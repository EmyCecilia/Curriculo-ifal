Seção 2

Ranking de Tecnologias Web

Classificadas da 5ª à 1ª posição em relevância para o curso.

  1. 5
    TypeScript

    Superset tipado do JavaScript que melhora a manutenibilidade em projetos grandes, reduzindo erros em tempo de desenvolvimento.

  2. 4
    CSS3 & Design Responsivo

    Além de estilização, o CSS moderno inclui variáveis, grid, flexbox e media queries, ferramentas essenciais para qualquer desenvolvedor front-end.

  3. 3
    Git & GitHub

    Controle de versão é uma habilidade transversal — nenhum projeto profissional prescinde de versionamento, histórico e colaboração via pull requests.

  4. 2
    JavaScript

    Única linguagem nativa dos navegadores, domina tanto o front-end quanto o back-end (Node.js). Compreendê-la em profundidade abre praticamente todo o ecossistema web.

  5. 1
    HTML5 Semântico

    A base de tudo na Web. Sem estrutura semântica sólida, acessibilidade, SEO e manutenibilidade ficam comprometidos — independente de qual framework ou linguagem se use por cima.

Seção 3

Glossário de Termos Técnicos

HTML
HyperText Markup Language — linguagem de marcação padrão para estruturar conteúdo na Web.
Define elementos como parágrafos, títulos, listas, tabelas e formulários por meio de tags.
CSS
Cascading Style Sheets — linguagem responsável pela apresentação visual de documentos HTML.
Controla cores, tipografia, espaçamento, animações e layout responsivo.
JavaScript
Linguagem de programação interpretada, orientada a eventos, que adiciona interatividade e lógica às páginas web.
URL
URI
Identificador que localiza um recurso na Internet, composto por protocolo, domínio, caminho e parâmetros opcionais.
DOM
Document Object Model
Representação em árvore de objetos de um documento HTML ou XML, manipulável via JavaScript para alterar conteúdo e estrutura dinamicamente.
API
Application Programming Interface — conjunto de definições e protocolos que permite que sistemas se comuniquem entre si.
HTTP
HyperText Transfer Protocol — protocolo de comunicação base da Web, responsável pela transferência de dados entre clientes e servidores.
DNS
Domain Name System — sistema que traduz nomes de domínio legíveis por humanos (ex.: ifal.edu.br) em endereços IP numéricos.
